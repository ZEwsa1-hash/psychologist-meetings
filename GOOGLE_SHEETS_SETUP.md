# Подключение формы к Google Таблице

1. Создайте Google Таблицу или откройте существующую.
2. В таблице выберите **Расширения → Apps Script**.
3. Замените содержимое файла `Code.gs` кодом из файла `google-apps-script.gs` этого проекта и сохраните.
4. Нажмите **Развернуть → Новое развертывание → Веб-приложение**.
5. Для поля «Выполнять как» выберите себя, а доступ разрешите всем посетителям сайта. Нажмите **Развернуть** и подтвердите разрешения.
6. Скопируйте URL веб-приложения, который заканчивается на `/exec`.
7. В файле `index.html` найдите:

   ```html
   data-google-script-url=""
   ```

   и вставьте URL между кавычками.
8. Откройте сайт, отправьте тестовую заявку и проверьте лист **Заявки**. Лист и заголовки создадутся автоматически.

Важно: после изменения серверного кода откройте **Развернуть → Управление развертываниями**, создайте новую версию и обновите действующее развертывание. Тестовый URL `/dev` для сайта не подходит.
